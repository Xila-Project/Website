# Tutorials

These walkthroughs guide your first experience with Xila. Follow one supported path and check the result at each stage.

| Tutorial                                   | You will learn to                                                    | Environment                                                                 |
| ------------------------------------------ | -------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [Run Xila natively](./native)              | Set up the checkout, check it, and interact with the native desktop. | x86_64 Linux with a Wayland session; WSL2/WSLg needs a GUI check.           |
| [Run Calculator in the browser](./browser) | Build a WASI guest, start browser-hosted Xila, and use Calculator.   | x86_64 Linux development environment and an OPFS/Web Locks-capable browser. |

Already familiar with Xila? Use the [how-to guides](/how-to/) to complete a specific task.
